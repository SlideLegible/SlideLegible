# Examples

`demo-low-contrast.pptx` is generated by `tests/fixtures/decks.py` (`demo_deck`) from code only, so it contains no third-party content. It covers a dark slide with low-contrast text, pale text on white, white text on a pale shape, a saturated red background, gradients (one fixable, one not), a photo-like background, a table, a watermark, and pure black/white for softening.
