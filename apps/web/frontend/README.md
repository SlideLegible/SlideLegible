# SlideLegible Web Frontend

This React and TypeScript app is served and built with Vite. npm is the selected package manager; `package-lock.json` records the resolved dependency tree.

Requires Node.js 20.19+ or 22.12+. From this directory:

```sh
npm ci
npm run dev
npm run build
```

The current page is a setup shell. Upload, analysis, and report review are not implemented yet.
